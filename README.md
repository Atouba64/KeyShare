# KeyShare

Starter repository for **KeyShare** — share and manage access credentials or keys with clear boundaries (design your security model before production use).

## Structure

| Path | Purpose |
|------|---------|
| `lib/` | Core library / shared modules |
| `docs/` | Architecture and usage notes |

## Security note

Do **not** commit real secrets, API keys, or private keys. Use `.env` locally and a secrets manager in production.
